# Provenance and team attribution

This is a public portfolio snapshot of the USC FindLy team project, maintained
by Atharva Sandeep Bhide (AthArvA-188). It is a collaborative project, not a
sole-authored implementation.

Original repository: https://github.com/snehanshu-raj/FindLy (access controlled).
Source revision: 55c6c9ed64431817fdede513265d1075acce3bb0
Snapshot prepared: 2026-11-03.

## Contributions

Atharva's recorded contribution includes the Python file-watcher daemon,
watcher configuration, and related documentation in `findly_engine/`.
The full application, embedding services, indexing pipeline, frontend, and
deployment setup represent the team's combined work.

## Snapshot scope

Tracked application source, documentation, and synthetic test fixtures are
preserved from the revision above. Generated indexes, local metadata,
compiled Python caches, and original Git history are deliberately excluded.
README attribution and additional ignore rules are the publication changes.
